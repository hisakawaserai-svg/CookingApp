# CookingApp (AIレシピインポート & 調理サポートアプリ)

Web上のテキストやメモ書きなどの「非構造化データ」から、Gemini APIを用いてレシピの「材料」や「調理手順」を自動解析・構造化し、スムーズな調理をサポートするReact Native（TypeScript）製アプリです。

## 📱 アプリの特徴とこだわり

- **AIによるレシピの構造化（Gemini API連携）**: 
  ネットで見つけた料理のメモや、箇条書きのテキストをペーストするだけで、AIが自動で「料理名」「材料」「前処理」「調理手順」に切り分けてデータベースに保存します。
  
- **「AIはミスをする」前提の親切なUI**: 
  AIの解析が間違っていたり、自分好みに調整したい時のために、保存前・保存後に関わらず、すべての項目を手動で修正・編集できる「手直し機能」を搭載しています。

- **スマートな調理フロー**:
  登録したレシピをもとに、調理の流れ（前処理・本調理）をステップごとに確認しながら快適に料理ができます。

- **文字 ＆ タグによる柔軟なフィルター**:
  保存したレシピが増えてもすぐに目的の料理が見つかるよう、フリーワード検索に加えて、自分で作成・カスタマイズした「タグ」による強力なフィルタリング機能を実装しています。

## 🛠️ 技術スタック
- **フロントエンド**: React Native (TypeScript)
- **データベース**: SQLite
- **AI連携**: Gemini API

## 💡 技術的な工夫・トラブルシューティング

### 1. セキュリティと環境変数の分離
セキュリティ対策として、GeminiのAPIキーなどの秘匿情報はGitの追跡対象から完全に除外（`.gitignore` に設定）し、リポジトリ公開時に環境変数が漏洩しないよう安全な開発フローを徹底しています。
